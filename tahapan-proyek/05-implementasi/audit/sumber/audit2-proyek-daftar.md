# AUDIT proyek-daftar — Proyek: DAFTAR, filter, Gantt (P1)

Basis: cabang `audit/pm-proyek-daftar` @ `161def2`. Dimensi 1, 2, 5, 6 (hanya layar daftar). Statis + 1 tes sementara (DB terisolasi, sudah dihapus; salinan di `/tmp/audit/evidence-proyek-daftar-probes.test.ts`).

**Ringkasan:** 9 temuan baru: Kritis 0 · Tinggi 1 · Sedang 3 · Rendah 5 (8 terkonfirmasi, 1 dugaan). Alur data tiap kontrol (cari, lingkup, status, perhatian, urut, tampilan, halaman) sudah benar dari URL sampai SQL: tak ada parameter hilang, kunci cache memuat semua parameter, kondisi List/Grid/Gantt/`?perhatian=1` satu fungsi (`toListItem`). Hak sudah dari server (`canCreate`, `canSeeAll`), loader memanggil `requireUser` paling awal, bentuk galat 422 seragam (terbukti), tak ada N+1 (7 pernyataan per halaman).
Masalah terbesar ada di Gantt (tahun ekstrem), teks tenggat proyek selesai, dan paginasi offset. **Sudah diketahui, tidak dihitung:** PRJ-01 (Eden `Date`) **masih ada** di `161def2`: regex `u` di `node_modules/@elysiajs/eden/dist/chunk-I5KHAGLL.mjs` mengubah `YYYY-MM-DD` tahun 19xx/20xx jadi `Date`, `eden.ts:13` tanpa `parseDate:false`, sehingga Gantt/Tenggat kosong setelah ganti tampilan di klien; juga PRJ-07, 08, 10, 12, 15, 17, 21, 25, H-B9, H-B11, H-C16.

## Kesesuaian wireframe ① / ② (daftar)
Ada: judul "Proyek"; tombol Proyek baru hanya `canCreate` (server); cari; segmented Proyek saya/Semua (Member: disembunyikan, server menjepit ke "saya"); List/Grid (+Gantt, tambahan S5a); chip Semua·Berjalan·Ditunda·Selesai·Draf; "Perlu perhatian" dengan pemisah; Urutkan (3 pilihan); kolom nama/status/kondisi+alasan/progres/tenggat; seluruh baris/kartu/batang bisa diklik; "Tampilkan lebih banyak"; kartu di mobile; kosong ② Member (tanpa tombol) dan Admin/PM. **Sebagian:** cari hanya nama (PRJ-10); "tenggat (diperpanjang ×1)" dan avatar anggota tidak ada (PD-07); Dibatalkan tak punya chip (disengaja, hanya lewat "Semua"). **Tambahan di luar wireframe:** empty state "attention" dan "filtered"; Gantt.

## Peta alur kontrol (terbukti dari kode)
Cari `q` → `slice(100)` → `trim` → `ilike(name)` (tanda `%`/`_` di-escape; tes: `q="… 100%"` hanya cocok literal). Lingkup `lingkup` → `scope` → `clampListScope` → subselect `project_member`. Status → `status`; `perhatian` menggantikan status (URL, query, dan `listProjects` konsisten; `status≠active`+`perhatian` → kosong). Urut → `ORDER` (`due`/`name`/`recent`) dengan tie-break `id` (total order). Tampilan → hanya `limit`+`rencana` (kunci cache berbeda, tak ada tabrakan List↔Grid). `hal` mati (PRJ-17). 422: `limit=1000`, `perhatian=2`, `page=0`, `sort/scope/status` salah → semua `{code,error,issues,method,path,requestId,status}`.

## Cakupan tes
Tanpa tes: rute `projects.tsx` (loader, `shouldRevalidate`, `useProjectPages`, penyemaian `seeded`, `getNextPageParam`); `ProjectFilters` interaktif (debounce 350 ms, sinkron `useEffect` URL↔kotak, `setFilters` beku); data hasil Eden (akar PRJ-01); `DueCell`/`settled`; paginasi bergeser (PD-03); tahun di luar 1900–2099 pada Gantt; `tests/app-routes.test.ts` memeriksa `require…(request` ada di berkas, bukan pernyataan pertama loader. Semua tes UI daftar memakai `renderToStaticMarkup`.

## Perlu dicek manual di browser (≤8)
1. Admin: buka `/app/projects`, klik "Gantt" (klien) → batang dan tenggat tampil? (PRJ-01) lalu muat ulang halaman: sekarang tampil? (SSR).
2. Ubah tenggat satu proyek jadi tahun 2062, buka Gantt: waktu muat, label bulan terpotong, batang lain menciut (PD-01).
3. Di dua tab: tab A urut "Terakhir diubah" + "Tampilkan lebih banyak"; di tab B edit proyek lama; kembali ke A → baris ganda/peringatan konsol (PD-03).
4. Pilih Gantt + "Semua proyek", klik satu batang, klik "Kembali ke daftar proyek" (PD-04).
5. Proyek Selesai dengan tenggat lampau: baca teks tenggat di List, Grid, kartu mobile (PD-02).
6. 375 px dan skala teks 150 %: baris saringan, kolom label Gantt (±228 px) dan geser horizontal, Sticky label menimpa batang?
7. Safari: klik sel mana pun di baris tabel membuka proyek (overlay `::after` pada `<tr position:relative>`).
8. Ketik cepat di cari lalu klik chip status dalam <350 ms: kata cari dan status keduanya bertahan.
