## Tabel 1 — Bagaimana 10 Kompetitor Menyusun Menu Inti

| Kompetitor | Urutan Menu (dari luar ke dalam) | Task-nya Apa? | Langkah Sebelum Bisa Kerja | Ramah Pemula |
|---|---|---|:---:|:---:|
| Trello | Board → List → Kartu | Kartu + checklist | 2 langkah | 🟢 Paling ramah |
| Smartsheet | Folder → Sheet → Baris | Baris (mirip Excel) | 2 langkah | 🟢 Ramah |
| Asana | Proyek → Bagian → Task | Task + anak-task | 3 langkah | 🟡 Cukup |
| monday.com | Board → Grup → Item | Item + sub-item | 3 langkah | 🟡 Cukup |
| Notion | Database bebas | Baris database | Bebas (harus atur sendiri) | 🔴 Sulit |
| Airtable | Base → Tabel → Baris | Baris (bukan istilah "task") | 3 langkah | 🔴 Sulit |
| Linear | Tim → Proyek → Issue | Issue + sub-issue | 4 langkah | 🔴 Sulit |
| Zoho Projects | Proyek → Daftar Task → Task | Task per daftar | 3–4 langkah | 🔴 Sulit |
| ClickUp | Folder → List → Task | Task + checklist | **5 langkah** | 🔴 Paling berat |
| Wrike | Folder → Proyek → Task | Task + dependency | **5 langkah** | 🔴 Paling berat |

**Kesimpulan:** makin banyak langkah setup di depan, makin sulit dipakai orang awam. Tidak satu pun dari 10 kompetitor benar-benar ramah untuk pengguna lansia/awam.

## Tabel 2 — Rekomendasi Core untuk PM Kita

| Menu | Isinya | Kenapa Begini |
|---|---|---|
| **Beranda** | Ringkasan task saya + status warna | Titik masuk paling sederhana, tanpa perlu paham struktur dulu |
| **Proyek** | Daftar Proyek → langsung berisi Task (tanpa folder wajib) | Cukup **2 langkah**: buat proyek → buat task. Proyek pertama jadi <60 detik |
| **Task** | Task datar + Checklist di dalamnya | Cukup untuk 80% kebutuhan; sub-task formal ada tapi jadi toggle opsional |
| **Status Task** | 🔴 Terlambat · 🟡 Dikerjakan · 🟢 Selesai | Warna dulu, teks belakangan — tidak perlu baca untuk paham progres |
| **Tampilan** | Board (Kanban) & List sederhana sebagai default | Dua tampilan paling dikenal orang awam; Calendar/Gantt disembunyikan di "Mode Lanjutan" |
| **Mode Lanjutan** (opsional, bisa dimatikan) | Sub-task berlapis, custom field, dependency, Gantt | Tersedia buat tim yang butuh, tapi tidak membebani pengguna baru |

**Prinsip inti:** 2 level struktur (Proyek → Task), istilah polos (bukan Base/Space/Issue/Portfolio), dan toggle Mode Simpel ⇄ Mode Lanjutan — pembeda yang belum dimiliki satu pun dari 10 kompetitor.
