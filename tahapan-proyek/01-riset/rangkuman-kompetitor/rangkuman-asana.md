# Rangkuman Kompetitor: Asana

**Tanggal riset:** 2026-09-26  
**Metode:** Eksplorasi langsung via ego-browser ke app.asana.com (akun aktif, free trial Advanced)  
**URL:** https://app.asana.com

---

## Gambaran Umum

Asana adalah platform manajemen proyek berbasis web yang ditujukan untuk tim dan organisasi. Asana memposisikan diri sebagai "work management platform" — bukan sekadar task manager, tapi mencakup goal setting, automation, AI, dan reporting dalam satu tool.

---

## Struktur Navigasi Utama

Asana menggunakan **5 tab navigasi utama** di sidebar kiri, masing-masing memiliki sub-menu tersendiri.

### 1. WORK
Pusat aktivitas kerja sehari-hari.

| Sub-menu | Fungsi |
|----------|--------|
| **Home** | Dashboard pribadi — ringkasan tugas, proyek aktif, widget "My week" |
| **Inbox** | Notifikasi dan update dari semua proyek yang diikuti |
| **My Tasks** | Daftar tugas milik sendiri — filter: Upcoming, Overdue, Completed |
| **Projects** | Daftar semua proyek di workspace dengan filter Owner, Members, Status |
| **Portfolios** | Kumpulan beberapa proyek dalam satu portofolio untuk monitoring lintas proyek |

**Tampilan di dalam setiap Proyek:**

| Tab View | Fungsi |
|----------|--------|
| **Overview** | Ringkasan proyek, status, milestone, anggota tim |
| **List** | Tampilan daftar tugas klasik dengan kolom-kolom (nama, due date, assignee) |
| **Board** | Kanban board — kartu tugas yang bisa di-drag antar kolom status |
| **Timeline** | Gantt chart — jadwal proyek, dependensi antar tugas, tanggal mulai-selesai |
| **Dashboard** | Grafik otomatis dari data proyek (progress, completion rate, dll) |
| **Calendar** | Tampilan tugas dalam format kalender bulanan |
| **Messages** | Obrolan tim dalam konteks proyek (mirip channel per proyek) |
| **Files** | Semua file/lampiran yang ter-upload dalam proyek |

---

### 2. AGENTS
Pusat AI dan otomasi.

| Sub-menu | Fungsi |
|----------|--------|
| **AI Teammates** | Bot AI yang bekerja otomatis — contoh: "Work Intake Specialist" untuk klasifikasi & routing request masuk |
| **Automations** | Rules berbasis if/then — misalnya: "jika tugas selesai → pindahkan ke Kolom Done → kirim notifikasi" |
| **Project Templates** | Template proyek siap pakai (cross-functional plan, 1:1 meeting, sprint planning, dll) |
| **Forms** | Formulir untuk menerima request dari orang di luar tim |
| **Custom Fields** | Kolom tambahan spesifik proyek (dropdown, number, date, text) |

---

### 3. STRATEGY
Perencanaan tingkat organisasi.

| Sub-menu | Fungsi |
|----------|--------|
| **Goals** | Hierarki target organisasi/tim — tracking otomatis (On track / At risk / Off track) |
| **Reporting** | Dashboard analitik dan laporan lintas proyek |
| **Resourcing** | Manajemen kapasitas dan workload anggota tim |

---

### 4. KNOWLEDGE
Dokumentasi dan rapat.

| Sub-menu | Fungsi |
|----------|--------|
| **Pages** | Dokumen kolaboratif (wiki, brief, spec, catatan) — mirip Notion, terhubung ke tasks |
| **Meetings** | Agenda rapat, catatan, dan action items yang terhubung langsung ke tugas Asana |

---

### 5. PEOPLE
Manajemen anggota dan tim.

| Sub-menu | Fungsi |
|----------|--------|
| **Profile** | Profil pribadi, foto, jabatan, out-of-office status, goals pribadi |
| **Teams** | Kelola workspace, undang anggota, lihat struktur tim |

---

### 6. MORE (Dropdown)
- **StackAI by Asana** — Tool untuk cross-system agentic workflows (terintegrasi dengan berbagai platform eksternal)
- **Customize Navigation** — Ubah urutan dan visibilitas tab navigasi

---

### 7. Elemen Global (Top Bar)

| Elemen | Fungsi |
|--------|--------|
| **Create** | Shortcut buat task, proyek, portofolio, goal, page, form, atau AI Teammate dari mana saja |
| **Search (⌘K)** | Universal search untuk semua konten Asana |
| **Work with Dash** | AI assistant bawaan — tanya pertanyaan tentang pekerjaan, minta ringkasan, draft pesan |
| **Help with Asana** | Dokumentasi, tutorial video, dan onboarding guide |
| **User Settings** | Profil, notifikasi, tema, integrasi aplikasi pihak ketiga |

## Fitur Unggulan

1. **Multi-view per proyek** — List, Board, Timeline, Calendar, Dashboard dalam satu proyek tanpa biaya tambahan (plan tertentu)
2. **Goal alignment** — Tugas bisa dihubungkan langsung ke goal organisasi, sehingga kontribusi setiap task terlihat
3. **Multi-homing** — Satu tugas bisa masuk ke beberapa proyek sekaligus tanpa duplikasi data
4. **AI Teammates** — Bot AI yang bisa menggantikan email intake, routing request, dan prioritisasi otomatis
5. **Automation (Rules)** — Otomasi berbasis trigger-action yang tidak memerlukan coding
6. **Template library** — Ratusan template untuk berbagai industri dan use case
7. **Integrasi luas** — 200+ integrasi: Slack, Google Drive, Zoom, Salesforce, GitHub, Jira, dll

## Analisis untuk Orang Awam / Pemula

### Keunggulan
- Ada widget "Learn Asana" di Home dengan video tutorial 3–15 menit langsung di dashboard
- Template proyek siap pakai sehingga tidak perlu mulai dari nol
- Tampilan Home yang personal — langsung tahu apa yang harus dikerjakan hari ini
- My Tasks menyederhanakan pengalaman: user bisa fokus hanya pada tugas sendiri

### Kelemahan
- **Terlalu banyak fitur sekaligus** — 5 tab × banyak sub-menu langsung terlihat semua tanpa mode "simpel"
- **Terminologi tidak intuitif** — "Portfolios", "Multi-homing", "AI Teammates", "Resourcing" tidak familiar bagi pengguna baru
- **Banyak klik untuk hal simpel** — Buat to-do list sederhana harus: buat workspace → proyek → section → baru task
- **Tidak ada mode lite** — Tidak ada toggle untuk menyembunyikan fitur advanced
- **Notifikasi banjir** — Inbox cepat penuh jika proyek aktif banyak dan tidak dikonfigurasi dengan benar

## Analisis Khusus untuk Orang Tua / Non-Tech User

### Keunggulan
- Panduan onboarding visual tersedia di dashboard
- Warna dan ikon cukup konsisten

### Kelemahan
- **Tidak ada versi mobile-lite atau interface simpel** — interface identik untuk semua level
- **Beberapa tombol hanya ikon tanpa teks** — membingungkan tanpa tooltip
- **Bahasa dominan Inggris** — tidak ada versi Indonesia yang lengkap
- **Setup awal butuh keputusan arsitektur** — harus tentukan struktur workspace, tim, proyek sebelum bisa produktif
- **UI sering berubah** — tutorial lama bisa tidak relevan karena Asana sering update tampilan
- **Harga tidak ramah** — fitur penting (Timeline, Reporting, Goals) hanya di plan berbayar ($10.99–$24.99/user/bulan); free plan sangat terbatas

## Kesimpulan: Profil Pengguna yang Cocok

| Profil | Cocok? | Catatan |
|--------|--------|---------|
| Tim startup/perusahaan 5–50 orang | ✅ Sangat cocok | Fitur lengkap, skalabel |
| Project manager berpengalaman | ✅ Sangat cocok | Timeline, Goals, Reporting sangat powerful |
| Tim enterprise 100+ orang | ✅ Cocok | AI, Goals, Resourcing untuk skala besar |
| Freelancer / solo user | ⚠️ Berlebihan | Terlalu banyak fitur untuk kebutuhan personal |
| Orang awam baru mulai | ⚠️ Perlu waktu | Kurva belajar cukup tinggi, perlu onboarding aktif |
| Orang tua / non-tech user | ❌ Tidak disarankan | Interface terlalu kompleks, terminologi asing |
| UMKM yang baru digitalisasi | ❌ Tidak disarankan | Lebih baik mulai dengan Trello atau Notion |

## Alternatif yang Lebih Simpel

- **Trello** — Kanban visual, sangat intuitif, bagus untuk orang awam
- **Todoist** — To-do list sederhana, tidak ada learning curve
- **Notion** — Lebih fleksibel dan dokumen-sentris, sedikit lebih ramah pemula
- **Google Tasks + Google Calendar** — Untuk non-tech user yang sudah familiar Google
