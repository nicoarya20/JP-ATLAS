# Brief Debat: Perombakan Menu Ringkasan

## Mosi
"Menu Ringkasan (14 card) sebaiknya dirombak menjadi 4 zona + KPI strip PM, seperti usulan di `diskusi/fitur-ringkasan.md`."

## Pihak
- **PRO**: mendukung perombakan.
- **KONTRA**: menolak perombakan, kekeh mempertahankan 14 card (atau paling jauh perbaikan kecil), dan **agresif menyerang** setiap argumen PRO.

## Bahan wajib dibaca (read-only, jangan diubah)
- `diskusi/fitur-ringkasan.md` — usulan + kritik awal (sumber utama).
- `hasil-orchestrasi/analysis/A1-dashboard-tim-events.md` — analisis asal usulan.
- `rangkuman-kompetitor/rangkuman-gabungan-usp.md` dan `rangkuman-kompetitor/gabungan-core-menu-dan-usp-langkah-lanjut.md` — riset kompetitor & segmen.
- Segmen target produk: **orang awam / lansia**. Tidak ada kompetitor yang ramah lansia; istilah asing & font kecil ada di 10/10 kompetitor.
- Board Penpot "Perbandingan Menu Ringkasan" isinya sama dengan fitur-ringkasan.md (Sebelum: 14 card 4 kelompok; Sesudah: Zona A Briefing AI, B Fokus Saya, C Tanya Data, D Agenda & Proyek, KPI strip PM).

## Aturan debat
1. Bahasa Indonesia, lugas. Maks ~600 kata per giliran.
2. Setiap klaim harus menunjuk bukti: kutip file + bagian, atau beri contoh skenario konkret (mis. "Bu Sri, 62 th, buka dashboard pagi hari...").
3. Wajib menanggapi **poin-poin spesifik** lawan dari giliran sebelumnya (beri nomor), bukan mengulang pidato pembuka.
4. Boleh mengakui poin lawan yang memang benar, tapi harus jelas apa yang diakui dan apa yang tetap dipertahankan.
5. Dilarang mengarang data/statistik. Kalau asumsi, tulis "asumsi".
6. Tulis HANYA ke file giliranmu sendiri di folder `diskusi/debat-ringkasan/`. Jangan sentuh file lain, jangan commit git.

## Format file giliran
```
# <PRO|KONTRA> — Ronde N
## Tanggapan atas poin lawan   (kosongkan di pembuka PRO)
## Argumen utama
## Serangan / pertanyaan balik untuk lawan
```
